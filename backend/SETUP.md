# חיבור האתר ליומן המשותף (גוגל שיטס)

אחרי החיבור, כל אימון שמתאמן קובע באתר נשמר אוטומטית בגיליון גוגל של אפיק ומופיע בדף הניהול (`/main`) עם הכתובת, הטלפון וההערות. אפיק גם מקבל מייל על כל הזמנה חדשה או ביטול, עם קישור ניווט ב-Waze.

זה חינמי לגמרי ולוקח בערך 5 דקות. צריך רק חשבון גוגל (של אפיק).

## שלב 1: גיליון חדש

1. נכנסים ל-[sheets.new](https://sheets.new) עם החשבון של אפיק.
2. נותנים לגיליון שם, למשל "אפיק – הזמנות".

## שלב 2: מדביקים את קוד השרת

1. בתפריט: **Extensions → Apps Script** (בעברית: **תוספים → Apps Script**).
2. מוחקים את כל מה שכתוב בעורך.
3. מעתיקים לשם את כל התוכן של הקובץ [`google-apps-script.gs`](google-apps-script.gs) ולוחצים על אייקון השמירה.

## שלב 3: קובעים סיסמה לדף הניהול

1. בעורך, בתפריט הצד, לוחצים על גלגל השיניים (**Project Settings**).
2. גוללים למטה ל-**Script Properties** ולוחצים **Add script property**.
3. Property: `ADMIN_PASSWORD`, Value: הסיסמה שאפיק ירצה. לוחצים **Save script properties**.
4. (לא חובה) אפשר להוסיף גם `NOTIFY_EMAIL` עם כתובת מייל אחרת לקבלת התראות. בלי זה, המיילים יגיעו לחשבון הגוגל שהתקין את הסקריפט.

## שלב 4: מפרסמים את השרת

1. למעלה מימין: **Deploy → New deployment**.
2. ליד Select type לוחצים על גלגל השיניים ובוחרים **Web app**.
3. **Execute as:** Me. **Who has access:** Anyone.
4. **Deploy**. גוגל יבקש לאשר הרשאות: בוחרים את החשבון, ואם מופיע "Google hasn't verified this app" לוחצים **Advanced → Go to … (unsafe)**. זה הסקריפט שלכם, ההודעה הזאת רגילה.
5. מעתיקים את ה-**Web app URL** (מתחיל ב-`https://script.google.com/macros/s/` ונגמר ב-`/exec`).

## שלב 5: מחברים את האתר

ב-`app.js`, בראש הקובץ, מדביקים את הכתובת:

```js
apiUrl: "https://script.google.com/macros/s/XXXXXXXX/exec",
```

שומרים, עושים commit ומעלים. זהו. נכנסים ל-`/main`, מקלידים את הסיסמה משלב 3, ורואים את היומן.

## שאלות

**איך בודקים שזה עובד?** פותחים את כתובת ה-Web app בדפדפן. אמור להופיע `{"ok":true,"service":"afik-booking"}`. אחר כך קובעים אימון ניסיון באתר ובודקים שנוספה שורה בגיליון.

**שיניתי את הקוד בעורך, והאתר לא מתעדכן.** אחרי כל שינוי בקוד השרת צריך **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. הכתובת נשארת אותו דבר.

**אפשר לערוך הזמנות ישירות בגיליון?** כן. אפשר לשנות את עמודת "סטטוס" ל"בוצע" או "בוטל", או לתקן כתובת. לא כדאי לשנות את סדר העמודות או את שורת הכותרות.

**כמה זה מאובטח?** הסיסמה נבדקת בשרת של גוגל ולא נמצאת בקוד האתר. רק מי שמכיר אותה רואה את פרטי המתאמנים. אחרי 10 ניסיונות שגויים הכניסה ננעלת ל-10 דקות. כל אחד יכול לראות אילו שעות תפוסות, אבל בלי שמות או כתובות.
