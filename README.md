# קביעת אימונים אצל אפיק

אתר לקביעת אימונים עבור אפיק, מאמן כושר אישי שמגיע עד הבית. האתר בנוי מ-HTML, CSS ו-JavaScript בלי ספריות, ושרת קטן אחד (`api/booking.js`) שרץ חינם ב-Vercel.

## מה יש באתר

- **אשף הזמנה בארבעה שלבים**: סוג אימון, יום ושעה, כתובת ופרטים, אישור. כולל פס התקדמות, אנימציות מעבר וולידציה עם הודעות ברורות.
- **לוח שנה חכם**: שבת סגורה, יום שישי עד 13:00, הפסקת צהריים, אין שריון פחות מ-3 שעות מראש, נקודות צבע שמראות כמה מקום נשאר בכל יום.
- **סיכום חי** בצד שמתעדכן עם כל בחירה, כולל מחיר מונפש, הנחת היכרות ותוספת נסיעה לפי עיר.
- **מסך הצלחה** עם קונפטי, הודעת וואטסאפ מוכנה לאפיק עם כל הפרטים, וכפתור הוספה ליומן גוגל.
- **"האימונים שלי"**: מגירה עם האימונים הקרובים, ספירה לאחור וביטול בלחיצה כפולה.
- **רשימת הכנה לבית** (2×2 מ׳, מים, מגבת…) שנשמרת במכשיר.
- מצב כהה ובהיר, נגישות מקלדת, תמיכה ב-`prefers-reduced-motion`, ותצוגה מותאמת לנייד.

## אימון בקבוצה

בשלב הראשון בוחרים "אימון לבד" או "אימון בקבוצה". בקבוצה:

1. מי שפותח את הקבוצה כותב את השם שלו ומסמן בטבלה שבועית מתי נוח לו (אפשר "כל הבקרים", "כל הערבים" או שעה-שעה; בעכבר אפשר לגרור).
2. מקבלים קישור (`/#g-XXXXXX`) ושולחים לחברים בוואטסאפ או בהעתקה. כל חבר פותח, כותב שם ומסמן את השעות שלו (עד 8 משתתפים).
3. האתר מראה רק שעות שמתאימות לכל המשתתפים **וגם** פנויות ביומן של אפיק בשלושת השבועות הקרובים. אם אין כאלה, הוא מראה שעות שמתאימות לכולם חוץ מאחד.
4. מישהו מהקבוצה בוחר שעה וממשיך לפרטים ולאישור כרגיל. כל השאר רואים בקישור שהאימון נקבע.

המחיר: מחיר האימון ועוד תוספת קבועה לכל משתתף נוסף (ברירת מחדל ₪100, משנים בהגדרות). בדף הניהול האימון מסומן "קבוצה" עם שמות המשתתפים. קבוצות נמחקות אוטומטית אחרי 45 יום.

## שעות טנטטיביות (שני ושלישי בערב)

בשני ושלישי בערב (16:00–21:00) אפיק בדרך כלל לא פנוי, אבל אפשר לשריין טנטטיבית. השעות האלה מופיעות בלוח עם מסגרת מקווקוות, ובבחירה מופיע הסבר שאפיק יעדכן עד יום לפני. בדף הניהול השריון מסומן "טנטטיבי · צריך לאשר", עם כפתור "מאשר, מסתדר לי" וכפתור שפותח הודעת וואטסאפ מוכנה להצעת שעה אחרת. בהגדרות, לחיצה על שעה בטבלת שעות הפעילות מחליפה בין סגור, פנוי וטנטטיבי, כך שאפשר להגדיר שעות טנטטיביות בכל יום.

## העלאה לאוויר (חינם, בלי חשבון גוגל)

האתר רץ על **Vercel** בחבילה החינמית. ההזמנות נשמרות ב-**Vercel Blob** (אחסון פרטי, גם הוא חינם), והשרת הוא הקובץ `api/booking.js`. אחרי ההעלאה:

- כל הזמנה מהאתר מופיעה מיד בדף הניהול של אפיק (`/main`), עם הכתובת, קוד לבניין, טלפון והערות, וכפתור ניווט ב-Waze.
- לוח השעות מציג את התפוסה האמיתית, ואי אפשר לשריין שעה שכבר נתפסה, גם אם שני מתאמנים לוחצים באותו רגע.
- מתאמנים יכולים לבטל מ"האימונים שלי", והביטול מתעדכן אצל אפיק.
- הסיסמה לדף הניהול נבדקת בשרת. בלי סיסמה נכונה אי אפשר לראות פרטים של מתאמנים.

### צעד אחר צעד (בערך 5 דקות)

1. נכנסים ל-[vercel.com/signup](https://vercel.com/signup) ובוחרים **Continue with GitHub** (אותו חשבון שבו נמצא המאגר הזה). בוחרים בחבילה **Hobby** (חינם).
2. **Add New → Project**, בוחרים את המאגר `afik` ולוחצים **Import**.
3. לפני הלחיצה על Deploy פותחים את **Environment Variables** ומוסיפים:
   - `ADMIN_PASSWORD` = הסיסמה שאפיק ירצה לדף הניהול.
   
   לוחצים **Deploy** ומחכים כדקה.
4. בפרויקט שנוצר: לשונית **Storage → Create Database → Blob**. בוחרים **Private**, נותנים שם (למשל `afik-bookings`) ולוחצים **Create**. בחלון שנפתח מסמנים את כל הסביבות ולוחצים **Connect**. זה מוסיף לבד את `BLOB_READ_WRITE_TOKEN`.
5. לשונית **Deployments**: ליד הפריסה האחרונה לוחצים על שלוש הנקודות → **Redeploy**, כדי שהשרת יכיר את האחסון.

זהו. האתר זמין בכתובת שמופיעה בפרויקט (למשל `afik-training.vercel.app`), ודף הניהול ב-`/main`. כל `git push` מעדכן את האתר אוטומטית.

**בדיקה מהירה:** פותחים `https://הכתובת-שלכם/api/booking` ורואים `{"ok":true,"service":"afik-booking"}`. אחר כך קובעים אימון ניסיון ובודקים שהוא מופיע ב-`/main`.

בלי שרת (למשל כשפותחים את `index.html` ישירות מהמחשב), האתר עובד במצב מקומי: ההזמנות נשמרות רק בדפדפן, והשעות התפוסות הן הדמיה.

## דף הניהול

מוסיפים לכתובת האתר `/main` (למשל `https://afik-training.vercel.app/main`) או `#main`, ונפתח מסך סיסמה. אחרי סיסמה נכונה נפתח דף הניהול של אפיק:

- כרטיס "האימון הבא" עם השעה, שם המתאמן, הכתובת המלאה, קוד לבניין, הערות וכפתורי ניווט ב-Waze ובמפות גוגל.
- סיכום: אימונים היום, 7 הימים הקרובים, הכנסה צפויה והזמנות חדשות.
- יומן אימונים מקובץ לפי ימים, עם סינון (קרובים, היום, היסטוריה, בוטלו), סימון כבוצע, ביטול ושחזור.
- כפתור "אישור בוואטסאפ" ששולח למתאמן הודעת אישור מוכנה.
- **הגדרות האתר** (לשונית בדף הניהול): שם המאמן, טלפון/וואטסאפ, אזור שירות, שעות פעילות לכל יום, סוגי אימונים (שם, משך, מחיר, תיאור, ציוד ואייקון), ערים ותוספת נסיעה, הנחת היכרות, כמה זמן מראש וכמה ימים קדימה אפשר לקבוע, מדיניות ביטול, ושינוי סיסמת הניהול. כל שינוי נשמר בשרת ומופיע באתר מיד, בלי לגעת בקוד.
- **הוספה ידנית**: אימון שנקבע בטלפון נכנס ליומן על ידי הדבקת הודעה בפורמט של האתר.
- היומן מתרענן לבד כל דקה. אחרי 10 סיסמאות שגויות הכניסה ננעלת ל-10 דקות.
- חמש סיסמאות שגויות נועלות את הכניסה ל-30 שניות. הכניסה נשמרת עד סגירת הדפדפן, וכפתור "יציאה" מנתק.

**באתר החי** הסיסמה היא מה שהוגדר ב-`ADMIN_PASSWORD` ב-Vercel, והיא נבדקת בשרת. משנים אותה ב-Settings → Environment Variables ואז Redeploy.

**במצב מקומי** סיסמת ברירת המחדל היא `afik2026`. הקוד שומר רק את ה-SHA-256 שלה. כדי להחליף, מריצים:

```bash
node -e 'console.log(require("crypto").createHash("sha256").update("הסיסמה-החדשה").digest("hex"))'
```

ומדביקים את התוצאה בשדה `adminPasswordHash` ב-`CONFIG`.

> במצב מקומי ההגנה היא בצד הדפדפן בלבד ומי שיודע לקרוא קוד יכול לעקוף אותה. במצב מחובר הסיסמה נבדקת בשרת, ופרטי המתאמנים לא נשלחים לדפדפן בלי סיסמה נכונה.

## התאמה אישית

את רוב ההגדרות משנים מלשונית "הגדרות האתר" בדף הניהול. הערכים שבראש הקובץ `app.js` (באובייקט `CONFIG`) הם רק ברירות המחדל עד השמירה הראשונה:

| שדה | מה הוא קובע |
| --- | --- |
| `apiUrl` | כתובת השרת (ברירת מחדל `/api/booking`). ריק = מצב מקומי |
| `adminPasswordHash` | SHA-256 של סיסמת דף הניהול (ראו למעלה) |
| `whatsapp` | מספר הוואטסאפ של אפיק בפורמט בינלאומי (למשל `972521234567`). **חובה לעדכן**, כרגע יש מספר דמה. |
| `phoneDisplay` | המספר שמוצג בתחתית העמוד |
| `workouts` | סוגי האימונים, משך, מחיר וציוד |
| `cities` | הערים שאפיק מגיע אליהן באופן קבוע ותוספת נסיעה לכל עיר |
| `allowAllCities`, `otherCityFee` | האם אפשר לבחור כל עיר בארץ (196 ערים ומועצות, או יישוב אחר בכתיבה חופשית), ומה תוספת הנסיעה לעיר שלא ברשימה |
| `hours` | שעות התחלה לכל יום בשבוע (0 = ראשון) |
| `firstTimeDiscount`, `minLeadHours`, `daysAhead`, `cancelHours` | הנחת היכרות, זמן מינימלי מראש, כמה ימים קדימה אפשר לשריין, מדיניות ביטול |

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
```
