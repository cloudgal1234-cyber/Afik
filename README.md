# קביעת אימונים אצל אפיק

אתר לקביעת אימונים עבור אפיק, מאמן כושר אישי שמגיע עד הבית. האתר סטטי לגמרי (HTML, CSS ו-JavaScript בלי ספריות), ואפשר לפרסם אותו ב-GitHub Pages, Netlify או Vercel בלי שרת.

## מה יש באתר

- **אשף הזמנה בארבעה שלבים**: סוג אימון, יום ושעה, כתובת ופרטים, אישור. כולל פס התקדמות, אנימציות מעבר וולידציה עם הודעות ברורות.
- **לוח שנה חכם**: שבת סגורה, יום שישי עד 13:00, הפסקת צהריים, אין שריון פחות מ-3 שעות מראש, נקודות צבע שמראות כמה מקום נשאר בכל יום.
- **סיכום חי** בצד שמתעדכן עם כל בחירה, כולל מחיר מונפש, הנחת היכרות ותוספת נסיעה לפי עיר.
- **מסך הצלחה** עם קונפטי, הודעת וואטסאפ מוכנה לאפיק עם כל הפרטים, וכפתור הוספה ליומן גוגל.
- **"האימונים שלי"**: מגירה עם האימונים הקרובים, ספירה לאחור וביטול בלחיצה כפולה.
- **רשימת הכנה לבית** (2×2 מ׳, מים, מגבת…) שנשמרת במכשיר.
- מצב כהה ובהיר, נגישות מקלדת, תמיכה ב-`prefers-reduced-motion`, ותצוגה מותאמת לנייד.

## היומן המשותף של אפיק

האתר מתחבר לגיליון גוגל דרך Google Apps Script (חינם, בלי שרת). אחרי החיבור:

- כל הזמנה מהאתר נשמרת אוטומטית בגיליון ומופיעה מיד בדף הניהול של אפיק, עם הכתובת, קוד לבניין, טלפון והערות.
- אפיק מקבל מייל על כל הזמנה חדשה וכל ביטול, עם קישור ניווט ב-Waze.
- לוח השעות באתר מציג את התפוסה האמיתית, ואי אפשר לשריין שעה שכבר נתפסה (גם אם שני מתאמנים לוחצים באותו רגע).
- מתאמנים יכולים לבטל מ"האימונים שלי", והביטול מתעדכן אצל אפיק.

**הוראות החיבור צעד אחר צעד: [backend/SETUP.md](backend/SETUP.md).** עד שמחברים, האתר עובד במצב מקומי (ההזמנות נשמרות רק בדפדפן, והשעות התפוסות הן הדמיה).

## דף הניהול

מוסיפים לכתובת האתר `/main` (למשל `https://example.com/main`) או `#main`, ונפתח מסך סיסמה. אחרי סיסמה נכונה נפתח דף הניהול של אפיק:

- כרטיס "האימון הבא" עם השעה, שם המתאמן, הכתובת המלאה, קוד לבניין, הערות וכפתורי ניווט ב-Waze ובמפות גוגל.
- סיכום: אימונים היום, 7 הימים הקרובים, הכנסה צפויה והזמנות חדשות.
- יומן אימונים מקובץ לפי ימים, עם סינון (קרובים, היום, היסטוריה, בוטלו), סימון כבוצע, ביטול ושחזור.
- כפתור "אישור בוואטסאפ" ששולח למתאמן הודעת אישור מוכנה.
- **הוספה ידנית**: אימון שנקבע בטלפון נכנס ליומן על ידי הדבקת הודעה בפורמט של האתר.
- היומן מתרענן לבד כל דקה.
- חמש סיסמאות שגויות נועלות את הכניסה ל-30 שניות. הכניסה נשמרת עד סגירת הדפדפן, וכפתור "יציאה" מנתק.

**אחרי החיבור לגוגל שיטס**, הסיסמה היא מה שהוגדר ב-`ADMIN_PASSWORD` בשרת, והיא נבדקת שם (ראו SETUP.md).

**לפני החיבור (מצב מקומי)** סיסמת ברירת המחדל היא `afik2026`. הקוד שומר רק את ה-SHA-256 שלה. כדי להחליף, מריצים:

```bash
node -e 'console.log(require("crypto").createHash("sha256").update("הסיסמה-החדשה").digest("hex"))'
```

ומדביקים את התוצאה בשדה `adminPasswordHash` ב-`CONFIG`.

> במצב מקומי ההגנה היא בצד הדפדפן בלבד ומי שיודע לקרוא קוד יכול לעקוף אותה. במצב מחובר הסיסמה נבדקת בשרת, ופרטי המתאמנים לא נשלחים לדפדפן בלי סיסמה נכונה.

## התאמה אישית

כל ההגדרות נמצאות בראש הקובץ `app.js` באובייקט `CONFIG`:

| שדה | מה הוא קובע |
| --- | --- |
| `apiUrl` | כתובת ה-Web App של השרת בגוגל (ראו backend/SETUP.md). ריק = מצב מקומי |
| `adminPasswordHash` | SHA-256 של סיסמת דף הניהול (ראו למעלה) |
| `whatsapp` | מספר הוואטסאפ של אפיק בפורמט בינלאומי (למשל `972521234567`). **חובה לעדכן**, כרגע יש מספר דמה. |
| `phoneDisplay` | המספר שמוצג בתחתית העמוד |
| `workouts` | סוגי האימונים, משך, מחיר וציוד |
| `cities` | הערים שאפיק מגיע אליהן ותוספת נסיעה לכל עיר |
| `hours` | שעות התחלה לכל יום בשבוע (0 = ראשון) |
| `firstTimeDiscount`, `minLeadHours`, `daysAhead`, `cancelHours` | הנחת היכרות, זמן מינימלי מראש, כמה ימים קדימה אפשר לשריין, מדיניות ביטול |

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
```
